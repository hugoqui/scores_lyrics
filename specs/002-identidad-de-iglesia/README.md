# 002-identidad-de-iglesia — Identidad de iglesia

**Estado:** ⬜ sin especificar · **Depende de:** 000, 001

## Objetivo

Crear la entidad iglesia, que hoy no existe en ninguna parte, y propagarla a los datos, los usuarios y los permisos. Incluye que un músico pueda pertenecer a una iglesia, tener varios instrumentos y varios dispositivos.
