# 000-seguridad — Seguridad

**Estado:** ⬜ sin especificar · **Depende de:** nada

## Objetivo

Rotar las credenciales filtradas y sacarlas del repositorio, cerrar el acceso público a la base de datos, y neutralizar la ejecución remota de comandos del agente de transmisión. Incluye el inventario de instalaciones, sin el cual la rotación no se puede coordinar: app y nodos comparten la misma base, así que rotar tumba a todos a la vez.
