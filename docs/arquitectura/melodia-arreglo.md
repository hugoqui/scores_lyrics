# Melodía y arreglo

> **Pendiente.** Este documento se escribe al especificar el módulo
> [`006-catalogo-y-partituras`](../../specs/006-catalogo-y-partituras/). Nace vacío a propósito: se llena con lo decidido,
> no con lo imaginado.

## Propósito

Cómo se modelan las partituras: grupos de melodía definidos por transposición y
clave, partes por instrumento, y deduplicación por contenido para que dos
músicos que leen la misma melodía no descarguen el archivo dos veces.
